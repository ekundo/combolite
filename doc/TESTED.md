# Что проверено

Результаты испытаний собранной платы в «Векторе-06Ц». Здесь только то, что
проверено на живом «Векторе»; что еще не проверялось — в конце, отдельно.

## Работает

| узел | как проверено | результат |
|---|---|---|
| питание | ток от блока 5 В по этапам сборки, напряжения `P3V3`, `P3V3_ESP`, `P1V2` | в норме, ориентиры — в [ASSEMBLY.md](ASSEMBLY.md) |
| ESP32-S3, Wi-Fi | первая прошивка по UART, настройка сети через точку `combolite-XXXX`, обновление прошивки и веб-интерфейса по воздуху | работает |
| прошивка ПЛИС | первый раз по JTAG (строка настроек), дальше с ESP по SSPI: стирание, запись, постраничная сверка | работает, 23-27 с на образ |
| квазидиск `10h` | тест записи и чтения всех страниц во всех режимах регистра: адресный, окна экрана, стековый, управляющий | 15 проходов без ошибок |
| квазидиск `11h` | тот же тест на порту `11h` | проходы без ошибок |
| винчестер IDE | CompactFlash 248 МБ: МикроДОС грузится с винчестера, CO, запуск программ; чтение и запись секторов через веб-интерфейс | работает; через ESP чтение 192 КБ/с, запись 41 КБ/с с проверкой |
| дисковод, прямой шлейф | Gotek: чтение каталога. Привод 3,5" с перемычкой DS0: форматирование 840 секторов, запись файлов, чтение обратно | без ошибок |
| дисковод, шлейф от ПК | выбор A: и B:, мотор, шаг головки | правильно; чтение и запись — см. ниже |
| выдержка мотора дисковода | после последнего обращения мотор крутится еще 3 с | работает |
| звук AY | программы с музыкой AY | работает; в паузах в колонках тихо, без фона |
| звук ВИ53 | программы со звуком таймера, без провода с контакта 42 | работает |
| USB-мышь | тест контроллера мыши KTSerg, arkanoid, сапер с поддержкой мыши | работает |
| колесо мыши | прокрутка колесом в клиенте Gopher | работает |
| Wi-Fi модем | терминал: команды AT; клиент Gopher: меню и файлы сайта на GitHub Pages через мост | работает |
| копия экрана | тестовые программы пишут известный узор во все четыре плана через `MOV M` и через `PUSH`; снимок с платы сравнивается побайтно | 32768 из 32768 байт в трех снимках подряд |
| VGA 60 Гц (720×900) | монитор HP L1908w с матрицей 1440×900 | монитор берет режим как 1440×900 при 60 Гц, картинка ровная |
| VGA 50 Гц (576p) | монитор HP L1908w | монитор берет режим (31,3 кГц / 50 Гц), картинка ровная |
| положение картинки и палитра | тесты бордюра BORD и BORD2, CLRS (256 цветов по лучу), CLRSPACE (таблица PAL): сравнение с эмулятором v06x и снимком BORD с настоящего «Вектора» | совпадает |
| мультиколор | демо Multicolor (S.E.S.), загрузчик, МикроДОС, CO | работает |
| кадр VGA без шва | игра Gobliiins: смена экранов с прокруткой, проявление палитры, 60 и 50 Гц | кадр VGA целиком из одного кадра «Вектора», срывов нет |
| снимок экрана | `combo.py screen`, веб-интерфейс, в том числе режим 512 точек | работает |
| подставной загрузчик | при включении, с платы (`combo.py loader boot`) и после ВВОД+БЛК с клавиатуры: BOOT26 грузит МикроДОС с винчестера, она запускается | работает; БЛК+СБР с клавиатуры BOOT26 не запускает, программа в памяти стартует как обычно |
| автозапуск после загрузчика ПЗУ | ВВОД+БЛК, загрузчик ПЗУ грузит с винчестера | плата сама нажимает СБР на мигании РУС/ЛАТ |
| запуск «Вектора» | плата держит ВВОД с включения и отпускает после сброса винчестера | «Вектор» не уходит в гудение, «антигудок» не нужен |

## Еще не проверено

| что | замечание |
|---|---|
| батарейка CR2032 | сколько хранится содержимое квазидисков без питания |
| подставной BOOT26 без автозапуска | BOOT26 должен домигать и ждать БЛК+СБР с клавиатуры; проверено в симуляции |
| дисковод, шлейф от ПК: чтение и запись | выбор, мотор и шаг проверены |
| «Векторы» с другой клавиатурой | ключи СБР и ВВОД проверены на одном «Векторе» |
| VGA 60 Гц через переходник VGA→HDMI | переходник проверялся с прежним режимом 800×600; 720×900 через него не пробовали |
| накопители кроме CompactFlash | DOM, SD через переходник, винчестер 2,5" |
| VGA 50 Гц на других мониторах и телевизорах | проверен один монитор |
| беспроводные мыши с общим приемником для мыши и клавиатуры | |
