# Плата ComboLite

Схема и плата — KiCad 10 (`kicad/combolite2.kicad_pro`). Лицензия —
CERN-OHL-S v2 ([LICENSE](LICENSE)).

## Файлы

| файл | что |
|---|---|
| `kicad/combolite2.kicad_sch` | схема |
| `kicad/combolite2.kicad_pcb` | плата |
| `kicad/symbols/`, `kicad/footprints/` | свои символы и посадочные места, подключены к проекту через `sym-lib-table` и `fp-lib-table` |
| `production/combolite2-fab.zip` | гербер и сверловка одним архивом — для заказа печати |
| `production/*.gbr`, `*.drl`, `*.gbrjob` | те же файлы по отдельности |
| `production/combolite2-bom.csv` | перечень элементов: позиции, номиналы, корпуса |
| `production/bom-digikey.csv` | номера производителей с количеством на одну и две платы — для загрузки в корзину дистрибьютора |
| `production/combolite2-top.pos`, `-bottom.pos` | координаты элементов, как их выводит KiCad |

3D-модели модуля ESP32-S3-WROOM-1U, гнезда SJ1-3515N, розетки USB Würth
629104151021 и разъема СНП34-90 в репозиторий не входят: это файлы
производителей. Плата открывается и без них, у этих деталей в 3D просто не
будет корпуса. Модели скачиваются с сайтов производителей и кладутся в
`kicad/packages3d/` под именами, на которые ссылается плата.

## Параметры заказа

| параметр | значение |
|---|---|
| габарит | 159,25 × 60,75 мм, прямоугольник |
| слоев | 6 |
| стек | `F.Cu` сигналы, `GND` сплошная земля, `Sig1` сигналы, `Sig2` сигналы, `3V3` сплошные 3,3 В, `B.Cu` сигналы |
| толщина | 1,6 мм |
| покрытие | ENIG |
| импеданс | не нужен, стек любой стандартный у завода на 1,6 мм |
| минимальный зазор | 0,13 мм |
| минимальная дорожка | 0,13 мм |
| переходные | 0,60 / 0,30 мм, 735 шт |
| медь до кромки | 0,30 мм |
| отверстий | 956, из них неметаллизированных 2 |
| круглые | 0,30 (747) · 0,90 (102) · 1,00 (91) · 1,30 (2) · 1,50 (1) · 1,70 (4) · 3,20 (2) |
| **пазы** | **0,70 × 2,30 мм — 2 шт, 1,00 × 2,00 мм — 5 шт** |

**Порядок медных слоев.** Внутренние слои названы по назначению, а не
In1..In4, поэтому завод может спросить порядок. Сверху вниз:

1. `combolite2-F_Cu.gbr`
2. `combolite2-GND.gbr`
3. `combolite2-Sig1.gbr`
4. `combolite2-Sig2.gbr`
5. `combolite2-3V3.gbr`
6. `combolite2-B_Cu.gbr`

**Пазы.** Отверстия с разными размерами по осям — это пазы, а не круглые
отверстия. Если производство прочитает их как круглые, разъемы не встанут.

## Сборка

Плата рассчитана на ручную пайку, по этапам — [doc/ASSEMBLY.md](../doc/ASSEMBLY.md).
Файлы `.pos` — как их выводит KiCad, без поправок на повороты корпусов, принятых
у конкретного завода: для заказа сборки их нужно сверить с требованиями завода.

## Особенности

- **`R114`** выбирает напряжение ядра ПЛИС: пятаки 1-2 («1V2») — для
  `LCMXO2-7000HE`, пятаки 2-3 («3V3») — только для сорта HC. HE на 3,3 В
  сгорит при первом включении.
- **`R121`** — на пятаки 1-2 («3V3»): питание стороны B трансляторов.
- **Не ставятся:** `C6`, `R14`, `R15`, `R108`.
- **Контакт 14 разъема дисковода `XS10`** не подключен. Шлейф от ПК с
  перекруткой поддержан режимом прошивки «шлейф от ПК» ([руководство](../doc/MANUAL.md), «Дисковод»).
