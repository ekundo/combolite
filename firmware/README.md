# Прошивка ESP32-S3

Модуль `ESP32-S3-WROOM-1U`, ESP-IDF 5.3.1. Лицензия — GNU GPL v3
([LICENSE](../LICENSE)).

Прошивка держит сеть и веб-интерфейс, раздает винчестер платы как сетевой
диск (NBD), читает и пишет его, когда «Вектор» к нему не обращается,
прошивает ПЛИС по SSPI, читает USB-мышь и обновляется по воздуху. С ПЛИС
модуль говорит по SPI.

| каталог | что |
|---|---|
| `*.c`, `*.h` | исходники |
| `esp32/` | проект ESP-IDF: `CMakeLists.txt`, разметка флеша `partitions.csv`, настройки по умолчанию |
| `../www/` | веб-интерфейс; при сборке уезжает в раздел SPIFFS |

## Сборка

    cd firmware/esp32
    idf.py set-target esp32s3
    idf.py build

Флеш модуля 4 МБ: два раздела приложения для обновления по воздуху и раздел
`www` под веб-интерфейс. Настройки сборки — в `idf.py menuconfig`, раздел
«Плата COMBOLITE»; по умолчанию менять ничего не нужно, сеть настраивается
уже на плате.

## Первая прошивка

Чистый модуль прошивается по UART через отверстия `TXD0`, `RXD0`, `IO0`,
`GND` у верхнего края платы: `idf.py -p ПОРТ flash` со свистком USB-UART или
`esptool` с Raspberry Pi. Провода и порядок — в
[doc/ASSEMBLY.md](../doc/ASSEMBLY.md), этап 3.

## Обновление

Дальше прошивка обновляется по Wi-Fi:

- **из веб-интерфейса** — плата раз в сутки проверяет раздачу готовых
  прошивок и ставит новую по нажатию. Образы в раздаче подписаны ключом
  автора, плата проверяет подпись открытым ключом из `pubkey.h`;
- **с компьютера** — своей сборкой:

      python3 tools/combo.py ota firmware/esp32/build/combolite.bin
      python3 tools/combo.py ota firmware/esp32/build/www.bin

  Первая команда заливает прошивку, вторая — веб-интерфейс. После прошивки
  плату перезагрузить: `python3 tools/combo.py reboot`.

Старая прошивка остается в запасном разделе: если новая не поднимется,
загрузчик вернется к ней.
